## Xbox Controller

You can use a standard Xbox-type game controller to adjust warp points more quickly and intuitively in WATCHOUT.

> Diagram placeholder: Xbox controller button map will be added here.

| Button | Action |
| --- | --- |
| `LEFT JOYSTICK` | Move the selected point dynamically in X/Y |
| `D-PAD` | Move the selected point exactly one pixel in X/Y |
| `RIGHT JOYSTICK` | Select next point in X/Y, including center points and bezier handles |
| `RB` | If multiple Warp windows are open, jump to the previously selected window |
| `LB` | If multiple Warp windows are open, jump to the next selected window |
| `X` | Undo last step |
| `Y` | Redo last step |

### Note

Any controller that emulates the standard Xbox model will usually work, but behavior can vary between vendors and some models may not expose all expected controls.
