# KEYBOARD SHORTCUTS

**Keyboard shortcuts let you work faster by providing direct access to common operations without navigating menus.** WATCHOUT 7 organizes shortcuts by workflow area so you can quickly memorize the commands you use most during programming, calibration, and rehearsal.

### Input and Editing

Core shortcuts for file handling and common edit actions.

- [File Operations](01-file-operations.md) - shortcuts for creating, opening, saving, and closing show files
- [Edit Commands](02-edit-commands.md) - context-sensitive shortcuts for cut, copy, paste, undo, redo, and selection commands that operate on the active edit target

### Navigation and Playback

Shortcuts for moving around Stage and Timeline quickly.

- [Stage Navigation](03-stage-navigation.md) - shortcuts for framing, scaling, and nudging content in Stage workflows
- [Timeline Controls](04-timeline-controls.md) - shortcuts for playback transport, cue selection, time navigation, and timeline editing operations

### Effects and Layout

Shortcuts for tween setup and workspace control.

- [Tween Shortcuts](05-tween-shortcuts.md) - shortcuts for toggling common animation and effect tracks on selected cues
- [Window Management](06-window-management.md) - shortcuts for switching between windows, toggling panels, and loading layout presets

### Hardware Input

Controller-based shortcuts for warp workflows.

- [Xbox Controller](07-xbox-controller.md) - game-controller mapping for selecting and moving warp points more intuitively
