# GETTING STARTED

**Welcome to WATCHOUT 7 -- the multi-display presentation and production system from Dataton.** Whether you are building a permanent installation, touring a live show, or creating an immersive experience, WATCHOUT lets you treat any arrangement of projectors, LED walls, and monitors as one giant canvas. This chapter walks you through everything you need to go from zero to your first running show.

### First Steps

Start here if you are new to WATCHOUT or setting up a fresh system.

- [Welcome to WATCHOUT 7](01-welcome-to-watchout-7.md) -- what WATCHOUT is, how the Producer/Display architecture works, and the "one giant canvas" concept
- [System Requirements](02-system-requirements.md) -- hardware and software requirements for Producer (editing) and Display (playback) computers
- [Installing WATCHOUT](03-installing-watchout.md) -- downloading, running the installer, selecting components, and installing drivers

### Setup and Configuration

Once WATCHOUT is installed, configure your environment for production.

- [Launching the Application](04-launching-the-application.md) -- starting Producer for the first time, choosing a layout preset, and launching the WATCHOUT Manager on display computers
- [Network Configuration](05-network-configuration.md) -- dedicated LAN requirements, switch selection, IP addressing, and firewall considerations for reliable multi-display synchronization
