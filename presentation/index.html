Asset Manager

The Asset Manager is the centralized service that handles the entire lifecycle of media in a WATCHOUT 7 show — from ingesting source files, through optimization (transcoding to GPU-friendly playback codecs), to distributing the results across every display server on the network.

How the Asset Pipeline Works

  1. Upload — files tracked as they are safely organized internally.
  2. Optimization — GPU-friendly transcoding using HAP codecs.
  3. Storage — sources retained & seamlessly deduplicated.
  4. Distribution — optimized assets transferred to each Runner.
