Audio Output and WATCHPAX Config

Audio output options and the WATCHPAX Config web interface for the WATCHPAX 64.

Audio

The WATCHPAX 64 is Dante-ready — a license can be purchased and activated to enable Dante audio output. See Dante License Activation for instructions.

Digital Audio Output Formats

WATCHPAX 64 can output multi-channel (7.1) LPCM audio embedded with DisplayPort and HDMI.

Digital audio output rates:

  • 44.1 kHz
  • 48 kHz
  • 88.2 kHz
  • 96 kHz
  • 176.4 kHz
  • 192 kHz

WATCHPAX Config

WATCHPAX Config is a browser-based configuration interface served by the WATCHPAX 64 on port 3024. It is used to manage EDID emulation, mosaic configurations, GPU topology, display settings, and static IP addresses. For access instructions and a full walkthrough, see Accessing WATCHPAX Config.
