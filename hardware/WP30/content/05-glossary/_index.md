## Glossary

**A–Z reference of terms, acronyms and technologies used in this guide.**

### Browse Terms

- Terms are listed alphabetically below.

### Aspect Ratio

The proportional relationship between a display's width and height. Common aspect ratios include 16:9 (widescreen), 16:10, 4:3 and 5:4. Aspect ratio determines how content is scaled to fit the display.

### CEA (Consumer Electronics Association)

An industry standards body responsible for defining video formats and timing specifications used in consumer displays. CEA Block timings are listed in the EDID emulator specification tables.

### Dataton

The Swedish company that manufactures the WATCHPAX series of media servers and develops the WATCHOUT multi-display production and playback software.

### Display Computer

A computer running WATCHOUT display software that renders and plays back show content. The WATCHPAX 30 functions as a dedicated display computer in a WATCHOUT production.

### EDID (Extended Display Identification Data)

A standardized data format that allows a display device (such as a projector, screen or monitor) to communicate its capabilities — including supported resolutions, refresh rates and timings — to a video source. See [EDID Emulators](../03-synchronization/01-edid-emulators.md).

### EDID Emulator

A small inline adapter that plugs into an HDMI output and stores a display's EDID data. This ensures the video source maintains a stable output resolution even when the display is temporarily disconnected. Four EDID emulators are included with the WATCHPAX 30.

### GPU (Graphics Processing Unit)

The dedicated graphics processor inside the WATCHPAX 30 responsible for rendering video output across the four HDMI display channels.

### HDMI (High-Definition Multimedia Interface)

A digital audio/video interface used to transmit uncompressed video and audio data from the WATCHPAX 30 to connected displays. The WATCHPAX 30 has four HDMI outputs.

### HDTV (High-Definition Television)

A display format with resolutions of 1280 × 720 (720p) or 1920 × 1080 (1080i / 1080p). HDTV formats appear in the EDID emulator supported resolutions.

### IEC C6

The type of power inlet connector on the WATCHPAX 30. It accepts the included IEC C6 power cord and supports 100–240V AC input at a maximum of 60 W.

### Kensington Security Slot

A small, reinforced slot on the rear panel of the WATCHPAX 30 compatible with standard Kensington cable locks, used to physically secure the unit against theft.

### Media Server

A dedicated computer designed for rendering and playing back media content. The WATCHPAX 30 is a media server optimized for WATCHOUT show playback, with a locked-down operating system and pre-installed WATCHOUT licenses.

### Producer

See *WATCHOUT Producer*.

### Production Computer

The separate computer running WATCHOUT Producer software, used for programming shows, editing timelines and distributing media to WATCHPAX units over the network.

### RJ45

The standard connector type used for Ethernet network cables. The WATCHPAX 30 has one RJ45 port on the rear panel for connecting to the WATCHOUT network.

### SDTV (Standard-Definition Television)

A display format with resolutions of 720 × 480i (NTSC) or 720 × 576i (PAL). SDTV formats appear in the EDID emulator supported resolutions.

### System Image

The pre-configured package containing the operating system, drivers and WATCHOUT software installed on the WATCHPAX 30. System image updates are provided by Dataton and include OS patches, driver updates and WATCHOUT software updates.

### Timecode

A timing reference signal used to synchronize playback across multiple devices. Timecode settings are retained when performing a "reset and keep user data" on the WATCHPAX 30.

### VESA (Video Electronics Standards Association)

An industry body that defines display interface standards, resolutions and timing specifications. VESA timing standards are referenced in the EDID emulator supported resolution tables.

### WATCHOUT

Dataton's multi-display production and playback software, available in version 6 and version 7. The WATCHPAX 30 includes built-in licenses for both versions.

### WATCHOUT Producer

The WATCHOUT application used on a separate production computer for show programming, timeline editing, media management and publishing shows to WATCHPAX display computers.

### WATCHPAX 30

A compact, dedicated media server manufactured by Dataton, featuring four HDMI video outputs, built-in WATCHOUT 6 and 7 licenses, and a locked-down operating system optimized for unattended media playback.
