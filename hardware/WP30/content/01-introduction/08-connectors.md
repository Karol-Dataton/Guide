## Connectors

**Overview of the WATCHPAX 30 front and rear panel connectors.** Use the numbered callouts in the images together with the reference tables below.

![WATCHPAX 30 Connectors - Front](../media/wp30/introduction_06.jpg)

### Front Panel

| No. | Connector / Label | Function | Notes |
|---|---|---|---|
| 1 | On/off switch | Power on/off | Recessed behind front plate — use a pencil or insulated tool to press |

![WATCHPAX 30 Connectors - Rear](../media/wp30/introduction_07.jpg)

### Rear Panel Connector Reference

| No. | Connector / Label | Function | Notes |
|---|---|---|---|
| 2 | IEC C6 power inlet | AC mains power input | 100–240V AC, 50/60Hz, max 60 W |
| 3 | HDMI output 1 | Video output channel 1 | Display output |
| 4 | HDMI output 2 | Video output channel 2 | Display output |
| 5 | HDMI output 3 | Video output channel 3 | Display output |
| 6 | HDMI output 4 | Video output channel 4 | Display output |
| 7 | RJ45 Ethernet | Network interface | Used for WATCHOUT network communication |
| 8 | USB ports | Peripheral connection | Keyboard, mouse, USB media |
| 9 | Kensington security slot | Anti-theft lock point | Compatible with standard Kensington locks |

:::info
Only use the power cord supplied with the WATCHPAX 30 unit. See [Accessories](03-accessories.md) for included items.
:::
