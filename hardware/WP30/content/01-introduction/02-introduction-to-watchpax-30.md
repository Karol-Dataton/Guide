## Introduction to WATCHPAX 30

**WATCHPAX 30 is a dedicated media server with four HDMI video outputs and a built-in Dataton WATCHOUT version 6 and 7 license.** WATCHPAX 30 is a locked-down unit, preconfigured for playback of WATCHOUT shows only.

WATCHPAX 30 has a handy compact format making it easy to transport. Other practical details include rubber bumpers and a Kensington security slot.

![WATCHPAX 30](../media/wp30/introduction_01.jpg)

### Key Specifications

| Category | Specification |
|---|---|
| Display outputs | 4 x HDMI |
| Networking | Ethernet (RJ45) |
| USB | USB ports for peripherals |
| Power | IEC C6 inlet, 100–240V AC, max 60 W |
| Dimensions | 215 x 32 x 176 mm (W x H x D) |
| Weight | 1550 g |
| Operating temperature | 0°C to +35°C (optimal 21°C–23°C) |
| Software | WATCHOUT 7 (default) and WATCHOUT 6 (built-in licenses) |
