## Quick Start

**A brief guide to getting your WATCHPAX 30 up and running.**

1. Connect displays to the WATCHPAX 30 using the HDMI outputs.
2. Connect the WATCHPAX 30 to the network using the Ethernet port.
3. Power up the WATCHPAX 30.
4. Start WATCHOUT software on the production computer which is on the same network. Make sure you are using WATCHOUT version 7, or WATCHOUT version 6.7.3, or higher.

:::info
If this is the first time powering up the unit (after delivery or after a reset), the system will finalize installation and reboot several times. This process typically takes about 5 minutes — do not interrupt it. WATCHOUT will start automatically when the process is complete. See [Installation](03-installation.md#first-power-on) for details.
:::

Once WATCHOUT is running and visible on the connected displays, the WATCHPAX 30 is ready to receive show data from WATCHOUT Producer.
