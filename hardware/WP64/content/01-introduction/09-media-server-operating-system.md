## Media Server Operating System

**The operating system in WATCHPAX 64 has been optimized and licensed for this specific media server configuration.**

:::info
Do not install or attempt to install any software on the locked-down media server (such as drivers, software updates, security updates, virus protection, etc). Doing so will automatically void the unit's warranty.
:::

For better security, media servers are recommended to be installed and operate on a separate network, without access to other networks.
