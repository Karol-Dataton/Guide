## Power

**Power inlet specifications for the WATCHPAX 64.**

| Specification | Value |
|---|---|
| Power inlet | IEC 60320 C14 |
| Input voltage | 100–240V AC, 50/60Hz |
| Maximum power consumption | 500 W |
| Typical power consumption | 200–300 W (varies with GPU load and number of active outputs) |

The WATCHPAX 64 ships with an IEC 60320 C13 power cord rated at 10A/250V AC — see [Accessories](03-accessories.md) for the full list of included items. Use only the supplied power cord; using a different cord may affect functionality and void the warranty.

For power-on and power-off procedures, see [Installation](../02-installation-and-operation/03-installation.md#power-on).
