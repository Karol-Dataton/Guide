## Quick Start

**A brief guide to getting your WATCHPAX 64 up and running.**

1. Connect displays to the WATCHPAX 64 using the DisplayPort outputs.
2. Connect the WATCHPAX 64 to the network using one of the Ethernet ports.
3. Power on the WATCHPAX 64.

:::info
The first time you power up a WATCHPAX 64 (after delivery or after a reset), the system will finalize its installation and reboot several times automatically. This process typically takes about **5 minutes** to complete. Do not disconnect power or interrupt the unit during this time. For full details, see [Installation — First Power On](03-installation.md#first-power-on).
:::

4. Once the startup process is complete, all connected displays will show the WATCHOUT startup screen, confirming the unit is ready. See [Start Up Screen](../01-introduction/06-start-up-screen.md) for details on the information displayed.
5. Start the WATCHOUT Producer software on the production computer, which is on the same network. Make sure you are using WATCHOUT version 7.
