## Quick Start

**A brief guide to getting your WATCHPAX 64 up and running.**

1. Connect displays to the WATCHPAX 64 using the DisplayPort outputs.
2. Connect the WATCHPAX 64 to the network using one of the Ethernet ports.
3. Power on the WATCHPAX 64.
4. Start the WATCHOUT Producer software on the production computer, which is on the same network. Make sure you are using WATCHOUT version 7.
