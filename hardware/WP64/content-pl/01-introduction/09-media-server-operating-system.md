## System operacyjny serwera

**System operacyjny w WATCHPAX 64 został zoptymalizowany i licencjonowany dla tej konkretnej konfiguracji serwera multimedialnego.**

:::info
Nie instaluj ani nie próbuj instalować żadnego oprogramowania na zamkniętym serwerze multimedialnym (np. sterowników, aktualizacji oprogramowania, aktualizacji zabezpieczeń, programów antywirusowych itp.). Takie działanie automatycznie unieważnia gwarancję urządzenia.
:::

Ze względów bezpieczeństwa zaleca się, aby serwery multimedialne były instalowane i pracowały w oddzielnej sieci, bez dostępu do innych sieci.
